# 隐私说明

更新日期：2026-11-23。

本应用为第三方、非官方作品，与 IT之家及软媒无隶属关系。

- 资讯、正文、评论和账号操作访问官方服务；官方网页、图片、视频及外部链接遵循各自服务的数据处理规则。
- 登录在独立官方窗口完成；同步后的必要 Cookie 仅在 Rust 后端使用，不传给前端或写入日志。
- 勾选保持登录时，使用当前 Windows 用户范围的 DPAPI 加密保存会话，不保存明文密码。加解密失败不退回明文。
- 配置、历史、本机收藏、草稿、文章和图片缓存保存在应用本地数据目录。会话以外的数据未承诺额外加密。
- 清理缓存保留配置、收藏及草稿。退出登录清除持久化会话并关闭官方窗口，按账号保存的草稿仍保留。
- 本版本没有第三方分析 SDK、遥测上传、后台消息推送或独立版应用内自动更新。
- GitHub Pages 托管官网，GitHub Releases 提供下载。请勿在公开 Issues 中上传 Cookie、会话文件、密码、验证码或其他个人敏感数据。

网站的隐私页面与本说明保持一致。
