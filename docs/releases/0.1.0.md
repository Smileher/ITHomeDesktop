Initial Windows preview of IT Home Desktop, an independent, unofficial client.

- Read official news channels and articles, browse comments, and keep local bookmarks and reading history.
- Restore per-account comment drafts and personalize themes, text size and cache limits.
- Use an isolated official-page window for sign-in and additional official services.

Account sign-in and write operations still require live-account validation. Native circles and message parity, background notifications and in-app updates are not complete. Microsoft Store packaging requires this application's Partner Center identity; this release is not Store approval. Windows ARM64 builds require separate hardware verification.
