# 0.1.5 Preview

- 修复全页面顶部背景只覆盖半幅的问题；个人中心四个入口改为吸顶横栏，收紧菜单、黑名单与账号内容布局，足迹在账号中心内显示。
- 阅读工具栏“查看评论”定位到评论区；正文下方仍可自然滚动浏览热门及全部评论，区内“写评论”及回复才打开输入弹窗。
- 原生消息中心接入未读数、会话与通知、新闻回复、圈子回复，以及会话历史与原文跳转。消息仅保留在当前页面内存；手动刷新，不自动标记已读。
- 圈子接入文字动态、回复、点赞与取消、收藏与取消。发帖话题取自实际话题列表；不填写设备伪装字段。登录后的详情与评论读取自身互动状态，避免写入公共缓存。
- 圈子草稿按账号单独保存在本机。写请求只提交一次，响应不确定时保留草稿并提示刷新核对；前后端均保留只读与登录校验。
- 使用 WebView2 官方低内存档位，保持旧运行时兼容；在相同程序和文章组中比较私有工作集与滚动帧间隔。此档位不是内存硬上限，结果随内容、系统和运行时变化。

消息及账号读取使用真实官方服务验证。发帖、回复、点赞和收藏写入使用隔离响应测试，没有向真实账号自动提交内容。图片/视频上传、私信发送、后台推送仍未接入。Microsoft Store 更新与独立版渠道保持分离。
