# 0.1.4 Preview

- 重新绘制应用图标；统一导航、列表、阅读区的层次配色与紧凑布局。
- 设置改为外观、阅读、账号、存储、关于五个分类；个人中心、收藏、黑名单改用更紧凑的布局，并显示真实用户头像。
- 接入官方个人资料、公开主题帖及需授权的文章评论、圈子回帖；点击头像可打开个人主页。
- 阅读图片使用官方 CDN 缩放图，进入视口才加载，离开视口释放图片源；共享有并发上限的图片加载队列。原图查看及保存仍使用原始地址。
- 评论保留在正文下方自然滚动，热门评论下方接全部评论；工具栏写评论和回复改为输入弹窗，保留按账号保存的草稿及只读校验。
- 收藏仅保留官方账号同步入口，统一称为“收藏”，使用五角星。旧的本机收藏数据保留，但移除功能入口。
- 专注阅读按钮置于最左，评论按钮置于最右并显示评论数；重复点击选中的资讯可收起正文，桌面分隔线可以拖动调整列表宽度。
- 修复图片关闭后残留空白/错误弹窗，阻止已关闭图片的异步请求更新弹窗状态。
- 禁用应用内右键菜单、F12 和开发者工具快捷键，同时禁用 WebView2 原生默认菜单及开发者工具入口。

本应用为第三方、非官方客户端。独立安装版与免安装包需要 WebView2。Store 分发与自动更新策略保持独立，后台消息推送尚未启用。账号写入操作未使用真实用户数据做自动化提交测试。
