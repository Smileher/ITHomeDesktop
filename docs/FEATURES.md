# 功能状态

此清单区分已实现代码、匿名联网验证和真实账号验证。预览版不是“所有官方功能已完全一致”的声明。

| 功能 | 当前实现 | 验证边界 |
| --- | --- | --- |
| 窗口自适应 | 桌面三栏；平板列表/阅读切换；手机全宽单栏、独立阅读与悬浮底栏 | 最小窗口宽度 360；底栏约 60px、胶囊圆角与小范围半透明磨砂 |
| 资讯、频道、分页 | 原生界面与真实接口 | 匿名接口可读取；按实时服务继续验证 |
| 正文、图像、阅读设置 | 清理 HTML 后排版、图片缓存与查看 | 视频等媒体依赖原文和系统支持；不允许嵌入脚本或 iframe |
| 评论与楼中楼 | 官方网页评论接口；热门/最新/最早、展开回复 | 匿名读取可验证 |
| 登录与保持会话 | 微信/App 扫码直达官方二维码，完成后自动核验同步；保留账号/短信登录和手动同步 | 两种真实二维码显示通过；手机确认登录流程尚需用户完成；DPAPI 保持登录，不保存密码 |
| 回复与点赞 | 按官方脚本实现，写请求不自动重试 | 未向真实用户发送测试评论或点赞 |
| 小尾巴 | 读取 App 评论协议返回的实际 `deviceTailModel.name`、额外尾巴和颜色；不提交设备伪装字段 | 当前匿名网页样本为空，但 App 读取已观察到真实设备名称；自己的尾巴仍取决于官方账号/客户端服务端是否返回 |
| 搜索 | 官方搜索页面的登录态读取；当前列表本地筛选 | 官方要求登录，需账号验证 |
| 收藏与历史 | 本机收藏/足迹保留；新增官方新闻收藏读取、添加和取消，以及帖子收藏读取 | 真实账号读取通过；写入只做受控响应验证，不修改真实收藏 |
| 草稿与配置 | 账号/回复隔离、SQLite、配置原子写入 | 单元及交互测试覆盖；配置当前版本为 1 |
| 圈子、好物、账号内容 | 好物原生列表；新版圈子、话题、详情/评论/楼中楼；账号评论、帖子、关注和黑名单 | 公开圈子及账号读取实测通过；圈子发帖/互动尚未接入，视频仍需官方客户端 |
| 账号中心 | 评论/帖子/收藏/足迹、草稿、黑名单；商城/资产/金币任务/投稿/资料/帮助的官方页面入口 | H5 页面能否完成资产和任务操作取决于官方网页及授权，不冒充原生实现 |
| 丰富设置 | 界面/正文字体、行距、正文图片、置顶卡片、圈子图片网格、输入框、自动打开文章、启动验证、只读模式 | 配置向后兼容；只读限制同时由原生后端执行 |
| 消息推送 | 未实现 | 后续先做驻留时同步；退出进程后的推送另需服务端条件 |
| 更新 | Store 分发渠道区分；独立版提供下载入口 | Store 由商店管理；独立版签名自更新是后续工作 |
| GitHub Pages | 中英文官网、隐私及下载页面 | 发布后检查公网地址 |
| Store | 构建脚本和工作流 | 正式身份及商店审核由 Partner Center 决定 |

## 后续顺序

1. 完成手机扫码确认、会话续期、回复、点赞和搜索的账号交互验证；处理服务端验证码或限制，不绕过验证。
2. 继续验证圈子写入、消息、官方 H5 账号流程和云收藏写入的实际交互。
3. 独立版接入新的更新签名密钥，支持下载校验与可控安装重启；Store 版继续使用商店更新。
4. 实现程序驻留时的消息同步和系统通知，核实退出后的推送条件。

实现中不为尚未确认的协议创建空接口或假数据页面。
